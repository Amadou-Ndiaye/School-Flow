
# SchoolFlow Sénégal

Application de gestion scolaire développée avec Django.

## Technologies

- Python
- Django
- PostgreSQL
- Django REST Framework

## Installation

1. Cloner le projet.
2. Créer un environnement virtuel.
3. Installer les dépendances.
4. Configurer le fichier .env.
5. Exécuter les migrations.
